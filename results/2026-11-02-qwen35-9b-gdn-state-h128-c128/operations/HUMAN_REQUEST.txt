三、必须区分两种实验
==================================================

实验 A：同一份 FP State 的配对旋转分析

目的：隔离观察“同一份 State 经过 Hadamard 后，分布和局部 C128 量化误差如何变化”。

做法：

1. 使用真实模型和真实 token 轨迹，取得某个 token、某一层的原始 FP State 快照 S。
2. 对同一份 S 构造：
   - Native：S；
   - Hadamard：将 S 按工程中实际使用的 Key-side H128 变换到对应基底。
3. 分别对这两份 State 做同一口径的 group size 128 INT8 局部 QDQ 分析。
4. 对比每个相同 sample、token、layer、head、value 组。

这一部分允许存在 FP 参考 State，因为它的目的就是做配对分析；但它不是物理 INT8 State 推理。图表和报告必须写清楚“共同 FP State 配对分析”，不能称为真实 INT8 递推结果。

请确认 Hadamard 的方向、归一化方式和矩阵顺序与实际 Qwen 实现一致。检查已有 patch 是否已对 State 或 q/k 做过旋转，避免重复旋转。对合成输入验证 H 的正交性和往返；再对真实模型做必要的算子/读出等价性检查。

由于 H128 是沿整个 128 元素 Key 组的正交变换，同一配对组的 L2 范数和 RMS 在数值误差内应保持一致。请把这作为一个检查项；如果明显不一致，优先排查旋转轴、归一化、分组和 dtype。

实验 B：真实 persistent INT8 State 轨迹

目的：观察真实逐 token INT8 State 运行时，Native 和 Hadamard 两种方案各自的分布。

要求：

1. Native 和 Hadamard 分别运行，各自维护自己的 State 轨迹；
2. 两者使用相同的 teacher-forced token 序列；
3. GDN State 必须在每个 token 更新后真实量化并以 INT8 存储，下一 token 从 INT8 State 和 scale 恢复后继续计算；
4. FP32/BF16 临时计算变量可以存在，但不能把 FP/BF16 持久 State buffer 上的 fake QDQ 宣称为真实 INT8 cache；
5. 如果覆盖 prompt prefill，也必须检查 prefill 的 State 递推是否逐 token 满足上述口径；否则只能如实标注实际覆盖范围，不能声称全程满足；
6. 统计可以每隔若干 token 采样，但真实 State 更新和量化必须每个 token 都执行。

请记录和核验 State buffer 的实际 dtype、shape、字节数、scale dtype、写回与下一 token 读取的数据流，以及实际逐 token 量化调用次数。

两条轨迹虽然使用相同 token，但其内部输入和 State 可能不同。因此，实验 B 的 Native/Hadamard 数据不能称为“同一份 State 旋转前后的严格配对”，也不能直接把所有差异归因于对同一张量做旋转。

六、每层需要统计哪些数据
==================================================

主统计必须覆盖每个采样时刻的所有有效 head、所有 value，以及各组全部 128 个 Key 元素。不能只用 head 0 或某个 value 的切片代表整层。

对每个 C128 组计算：

1. 原始 State：
   - min、max、absmax、RMS；
   - absmax / (RMS + eps)；
   - Pearson 峰度，即普通峰度，不是 excess kurtosis。

2. INT8 局部量化：
   - scale；
   - 量化前后相对 L2 误差：
     ||dequant - source||₂ / (||source||₂ + eps)；
   - 必要时记录 code 的边界占用率，但不要把它误称为 clipping。

3. 明确定义的异常值比例：
   - |x| > 3 × group_RMS 的元素比例；
   - |x| > 6 × group_RMS 的元素比例；
   - 记录判断阈值、分母和有效元素数。

全零组、零方差组以及 NaN/Inf 要单独计数。零方差组的峰度应标为未定义，不要填成 0 冒充有效结果。

按层和 head 汇总：

- group absmax、absmax/RMS、scale、峰度、QDQ 相对 L2 的 median、p95、p99；
- 3×RMS 与 6×RMS 异常元素比例；
- 总元素数、总组数、有效样本数及 token 数；
- 可选整体 QDQ 相对 L2，并写明计算方法。

分位数的观察单位要明确。例如，“所有已采样 group 的 p99”不能用“先算每个 token 的 p99，再对 token 取中位数”冒充。

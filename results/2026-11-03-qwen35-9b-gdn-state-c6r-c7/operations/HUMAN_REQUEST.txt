==================================================
四、实验配置
==================================================

四种配置：

1. Native：不旋转；
2. Hadamard：上一轮使用的归一化 Sylvester H128；
3. C6R：每层加载对应的已训练旋转；
4. C7：每层加载对应的已训练旋转。

所有配置使用一致的 Key-side C128 对称 INT8 量化口径。

上一轮量化公式为：

scale = max(abs(x), Key).clamp_min(1e-12) / 127
codes = round(x / scale).clamp(-127, 127).to(int8)
dequant = codes.float() * scale

其中：

- x 是固定 head/value 后，Key 轴的 128 个元素；
- torch.round 采用 ties-to-even；
- scale 为 FP32；
- 局部 GDN State 更新和量化公式沿用上一轮的 FP32 口径；
- 统计归约沿用 FP64 口径；
- 不将 |code|=127 的边界占用直接称为 clipping；
- NaN/Inf 不得静默替换。

请记录实际模型、输入、checkpoint、运行代码、环境和 GPU 身份。
模型和环境与上一轮有差别时，明确说明差别及其对历史结果可比性的影响。

五、实验 A：同一个 FP State 上的严格配对比较
==================================================

目的：单独比较四种变换对同一个 State 的影响。

执行方式：

1. 使用与上一轮相同的输入，回放 FP reference trajectory；
2. 在每个预定采样位置、每个 GDN 层，捕获同一个 FP State；
3. 对这个 State 分别计算：
   - Native；
   - Hadamard；
   - 该层对应的 C6R；
   - 该层对应的 C7；
4. 对四份结果使用相同统计和局部 INT8 QDQ 公式。

同一条记录的配对单位是：

sample_id + token_idx + model_layer_id + head_idx + value_idx。

每组覆盖完整 128 个 Key 元素。

实验 A 的量化只用于观测局部误差，不能将 QDQ 结果写回 FP reference，
也不能让某一种旋转改变另外三种旋转看到的 State。

注意：

- C6R/C7 不一定是对称矩阵，Hadamard 的对称性可能掩盖转置错误；
- 请参考原评测实现确定方向；
- 用非对称的合成正交矩阵和真实层验证旋转方向；
- 在不量化时验证旋转前后的 GDN 读出及 State 恢复一致性；
- 按实际计算精度报告误差和容差，不能只根据公式声称等价。

对于正交旋转，应检查每组旋转前后的 L2 范数/RMS 是否在数值误差内一致。
如果不一致，先核查矩阵、方向和实现；不要把问题直接解释为 outlier 改变。

六、实验 B：真实 INT8 持续写回
==================================================

目的：比较四种配置在真实循环量化轨迹中的 State 分布。

四种配置分别运行各自的 teacher-forced trajectory：

- B-Native；
- B-Hadamard；
- B-C6R；
- B-C7。

要求：

1. 从 prompt 的第一个 token 开始，所有 GDN 层每一步更新后，
   都将 recurrent State 实际编码并写入 INT8 codes + FP32 scales；
2. 下一步必须从对应配置自己的 INT8 codes 和 scales 恢复 State；
3. 不允许用 FP32/BF16 State 作为持久 carrier，再把它称为物理 INT8；
4. 允许每一步临时反量化为 FP32 计算，但临时张量不能作为持久 State 保留；
5. 不使用高精度窗口缓冲或隔 token 量化；
6. 不同配置的状态、缓存和读写路径必须隔离；
7. 根据实际可用显存决定同时批处理还是顺序运行，不得因此减少样本或改变量化条件。

请给出真实运行证据：

- 每层 codes/scale 的 shape、dtype、bytes；
- 每层逐 token 写回次数；
- 后续读回路径检查；
- 缓存中不存在额外的持久 FP/BF16 recurrent State；
- 每个配置的样本、token 和层覆盖情况。

实验 B 的每步 QDQ 误差，请基于“该步更新完成、写入 INT8 之前”的
FP32 临时 State 计算。不要对已经量化再恢复的 State 重复 QDQ，
再把接近零的结果当作真实本步量化误差。

四条 B 轨迹虽然输入 token 相同，但内部 State 和隐藏输入可能逐渐不同。
B 的比较应称为“相同输入条件下的独立递推轨迹比较”，
不能解释为同一个 State 的严格旋转配对。

==================================================
七、统计指标
==================================================

对于每个配置、每层、每个采样事件的所有 head/value 组，统计：

1. RMS：
   sqrt(mean(x^2))。

2. 峰均比 peak/RMS：
   max(abs(x)) / (RMS + 1e-12)。

3. outlier 元素比例：
   - abs(x) > 3 × 本组 RMS；
   - abs(x) > 6 × 本组 RMS。
   使用严格大于，并按实际元素数加权。

4. 峰度：
   使用上一轮的 centered Pearson kurtosis，不减 3；
   零方差时标为未定义，不要填 0。

5. INT8 scale。

6. 局部 QDQ 相对 L2 误差：
   norm(QDQ(x)-x) / (norm(x)+1e-12)。

7. absmax，以及各指标的 median、p95、p99。

8. pooled QDQ relative L2：
   sqrt(sum(squared_error)) / (sqrt(sum(squared_norm)) + 1e-12)。

统计时注意：

- 明确区分“所有 group 的精确分位数”和“先对每个 token 求分位数再平均”；
- 输出零组、未定义值和非有限值计数；
- 百分比、比例和原始数值单位要标清；
- 每层每条件预期有 2,113,536 个 group 观察，
  对应 270,532,608 个元素观察；
- 同一题的不同 token/head/value 是重复观察，不是独立题目样本。
